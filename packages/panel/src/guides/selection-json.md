# JSON

Uses [`state.selection.toJSON(state)`](https://wordgard.net/docs/ref/#state.GardSelection.toJSON).

- `side`: the side the [head is associated with](https://wordgard.net/docs/ref/#state.GardSelection.headSide). -1 is what comes before it, 1 what comes after. It decides where the cursor is drawn at a line wrap or in bidirectional text, and where motion takes it.
